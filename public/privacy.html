What we collect

By default we do not collect your workouts. Training logs, body weight, profile, and settings stay in this browser. Our servers do not receive that data.

On this device

The app stores data in this browser’s localStorage. Clearing site data deletes it. In Profile, Export backup downloads a JSON copy. Import backup restores that file.

Optional cloud sync

Google sign-in is not enabled on the public site today. If it is turned on later and you choose to sign in, your workout JSON is sent over HTTPS and stored in the operator’s Cloudflare D1 database, along with the Google user id, email, name, and picture used as the account key. You can keep using the app without an account.

Third parties

No advertising SDKs and no analytics trackers. If you use Google Sign-In, that sign-in is covered by Google’s terms.

Delete your data

On this device: Profile → Clear all data, or clear this site’s data in the browser. If you have turned cloud sync on, email us and we will delete the cloud copy. There is no in-app button for the cloud copy yet.

Product contact. Not a personal inbox.

我們收集甚麼

預設我們收不到你的訓練紀錄。訓練、體重、個人資料同設定都留在這個瀏覽器，伺服器收不到這些資料。

本機儲存

資料存在此瀏覽器的 localStorage。清除網站資料，紀錄就會消失。在「個人」可匯出 JSON 備份，也可以匯入還原。

可選的雲端同步

公開網站目前沒有開啟 Google 登入。若日後開啟，而且你選擇登入，訓練 JSON 會經 HTTPS 存到營運方的 Cloudflare D1，並保存 Google 提供的使用者 id、電郵、名稱同頭像作為帳號。不登入也可以繼續使用。

第三方

沒有廣告 SDK，也沒有分析追蹤。若使用 Google 登入，該登入受 Google 條款約束。

刪除資料

本機：到「個人」按「清除全部資料」，或在瀏覽器清除此網站資料。若已開啟雲端同步，請電郵我們刪除雲端副本。App 內尚未提供刪除雲端副本的按鈕。
